# 表示切り替えスイッチをはんだ付けする

espoke の LCD の表示ページを切り替えるスイッチ（押しボタン）を、はんだ付けで取り付ける手順です。
電子工作が初めてでも迷わないように、道具の準備から動作確認まで順番に書いています。

ブレッドボードは挿し込むだけで手軽な反面、線が浮いたり抜けたりして接触が不安定になりがちです。
スイッチ側をはんだ付けしてしまえば、そうしたトラブルがなくなります。

---

## 完成イメージ

```
  タクトスイッチ                          Raspberry Pi Pico WH
  ┌─────────┐
  │A ●   ● B│
  │   (◯)   │ ← 押すところ
  │C ●   ● D│
  └─────────┘
   A ── 電線 ── メスのコネクタ  →  20番ピン（GP15）
   D ── 電線 ── メスのコネクタ  →  18番ピン（GND）
```

- **スイッチ側だけはんだ付けします。** Pico WH にはピン（ピンヘッダ）が最初から付いているので、
  Pico 本体にはこてを当てません。
- Pico とはメスのコネクタで**挿すだけ**でつなぎます。失敗しても Pico を傷めずにやり直せます。

---

## 1. 用意するもの

| もの | 数 | 説明 |
|---|---|---|
| タクトスイッチ（4本足） | 1 | 押している間だけ電気が通るボタン。6mm 角のものが一般的 |
| ジャンパワイヤ（**メス-メス**） | 1本 | 両端が穴になっている線。半分に切って2本分として使う |
| はんだごて | 1 | 温度調節付きなら 330〜350℃ くらいに設定 |
| こて台 | 1 | 熱いこてを置く台。こてを机に直接置かない |
| はんだ | 少し | 電子工作用の細いもの（直径 0.6〜0.8mm くらい）。「やに入り」と書いてあるもの |
| ニッパー | 1 | 線を切る道具 |
| ワイヤーストリッパー | 1 | 線の被覆（周りのビニール）をむく道具。なければニッパーでも可 |
| 熱収縮チューブ | 少し | 温めると縮むチューブ。はんだ付けした部分を覆って絶縁する。なければビニールテープ |
| テスター | 1 | あれば安心（なくても作れる） |

**あると便利なもの**

- **マスキングテープ**：スイッチを机に貼って固定すると、両手が使えて作業しやすい
- **濡らしたスポンジ**（こて台に付いていることが多い）：こて先の汚れを拭く

## 2. 用語

| 言葉 | 意味 |
|---|---|
| **ピン** | Pico の縁に並んでいる金属の足。全部で40本あり、1〜40の番号が付いている |
| **GP15** | Pico のピンの名前の一つ。プログラムからは「15番」として扱う。**物理的には20番ピン**なので注意 |
| **GND**（グランド） | 電気の基準（0V）になるピン。Pico には GND が何本もある |
| **はんだ** | 熱で溶ける金属。溶かして部品と線をくっつける |
| **予備はんだ** | 本番の前に、線や足にはんだを薄く乗せておくこと。こうしておくとくっつきやすい |
| **ショート** | つながってはいけない場所どうしが触れて、電気が通ってしまうこと |

## 3. スイッチの足について（大事）

4本足のタクトスイッチは、中で**2本ずつつながっています。**

```
   A ●━━━━━━━━● B      A と B は、押していなくても常につながっている
     │   ◯    │        C と D も、押していなくても常につながっている
     │        │        押すと、A・B と C・D がつながる
   C ●━━━━━━━━● D
```

「常につながっている2本」を選んでしまうと、押しても押さなくても同じなので、スイッチとして働きません。

> **迷ったら対角の2本（A と D、または B と C）を使う。**
> 対角の2本なら、スイッチをどちら向きに置いても必ず「押したときだけつながる」組み合わせになります。

使わない B と C の足は、邪魔ならニッパーで短く切っておきます。

---

## 4. Pico WH のどのピンにつなぐか

Pico WH を **USB コネクタが上** になるように置きます。
左の列の上から 1, 2, 3 … 20、右の列の下から 21, 22 … 40 と番号が付いています。

```
             USB
         ┌───┴───┐
   1  ●  │       │  ●  40
   2  ●  │       │  ●  39
   3  ●  │       │  ●  38
   ⋮     │       │     ⋮
  17  ●  │       │  ●  24
  18  ●  │       │  ●  23      ← 18番ピン = GND（左の列、下から3番目）
  19  ●  │       │  ●  22
  20  ●  │       │  ●  21      ← 20番ピン = GP15（左の列、一番下）
         └───────┘
```

| スイッチの足 | つなぐ Pico のピン | 見つけ方 |
|---|---|---|
| A | **20番ピン（GP15）** | 左の列の**一番下** |
| D | **18番ピン（GND）** | 左の列の**下から3番目** |

**気をつけること**

- Pico WH の表側（部品が載っている面）には **GP の番号が印刷されていません**（裏側にだけあります）。
  「GP15 だから上から15番目」ではありません。上から15番目のピンは GP11 で、別のピンです。
- **19番ピン（GP14）と間違えないように。** 20番と18番の間にある1本は飛ばします。

## 5. はんだ付けの手順

### 5.1 線を準備する

1. メス-メスのジャンパワイヤを**真ん中で切ります**。コネクタ付きの線が2本できます。
2. 切った側の先の被覆（ビニール）を **3〜5mm むきます**。
3. 中の細い銅線が何本も出てくるので、**指でねじって1本にまとめます**。バラバラのままだと、はみ出した1本がほかの場所に触れてショートの原因になります。

### 5.2 熱収縮チューブを先に通す

4. 熱収縮チューブを 1.5cm くらいに切って、**線に通しておきます。**

> **はんだ付けの前に通すのを忘れがちです。**
> はんだ付けした後では、コネクタが引っかかって通せません。

チューブは、はんだ付けの熱で縮まないように、先から少し離れた位置まで下げておきます。

### 5.3 予備はんだ

5. こてが温まったら、濡れたスポンジでこて先を軽く拭きます。
6. **線の先**にこてを当て、そこにはんだを当てて少し溶かし込みます。銅線が銀色になれば OK です。
7. **スイッチの足（A と D）**にも同じようにはんだを少し乗せます。

### 5.4 線と足をくっつける

8. スイッチの足 A に、線の先を沿わせます。
9. 両方にこてを当てて、はんだが溶けて一つになったら**こてを離します。**
10. はんだが固まるまで（数秒）**動かさずに待ちます。** 途中で動かすと、表面がザラザラして割れやすい「イモはんだ」になります。
11. もう1本の線を足 D に同じようにくっつけます。

> **こてを当てるのは1回 2〜3秒まで。**
> タクトスイッチは樹脂（プラスチック）でできていて、長く熱を加えると中が溶けて、
> 押しても反応しなくなります。うまくいかなければ、一度冷ましてからやり直してください。

**うまくできたかの見分け方**

| 良い | 悪い |
|---|---|
| 表面がツヤツヤで、なめらかな山の形 | 表面がザラザラ、ボソボソしている |
| 線と足の両方にはんだがなじんでいる | はんだが丸い玉になって乗っているだけ |
| 引っ張っても取れない | 軽く引っ張ると取れる |

### 5.5 絶縁する

12. 下げておいた熱収縮チューブを、はんだ付けした部分にかぶせます。
13. ドライヤーの温風か、こての側面（先ではなく根元に近い部分）を近づけて温めると、チューブが縮んで固定されます。

熱収縮チューブがなければ、ビニールテープを巻きます。
**A と D の金属部分が触れ合わないようにする**のが目的です。

---

## 6. テスターで確認する（テスターがある場合）

Pico につなぐ前に、スイッチが正しく働くか確かめます。

1. テスターを**導通チェック**（音のマーク 🔊 や `))))` のマーク）に合わせます。
2. 2本の線の先（メスのコネクタの穴）に、テスターの棒を1本ずつ差し込みます。

| 状態 | テスターの結果 | 判定 |
|---|---|---|
| 押していない | 鳴らない | ✅ 正しい |
| 押している | ピーッと鳴る | ✅ 正しい |
| 押していなくても鳴る | — | ❌ 常につながっている組の足を使っている。対角の足に付け直す |
| 押しても鳴らない | — | ❌ はんだが付いていないか、スイッチが熱で壊れた |

---

## 7. Pico につなぐ

1. **USB ケーブルを抜いて、Pico の電源を切ってから**作業します。
2. 足 A の線のコネクタを **20番ピン（GP15）** に挿します。
3. 足 D の線のコネクタを **18番ピン（GND）** に挿します。
4. 奥までしっかり挿さっているか確認します。

> スイッチには向き（プラス・マイナス）がないので、A と D の線を逆に挿しても動きます。
> 大事なのは「20番ピンと18番ピンに1本ずつ」挿すことです。

---

## 8. 動作確認

1. USB ケーブルを挿して、Pico の電源を入れます。
2. LCD に通常の表示（曲名や `WiFi ok` など）が出るまで待ちます。
3. スイッチを押すたびに、LCD の表示が次の順に切り替われば完成です。

| 何回押したか | 1行目 | 2行目 |
|---|---|---|
| 0回（起動直後） | 曲名 / 状態 | 再生の進み具合 |
| 1回 | `WiFi -50dBm` など | IP アドレス |
| 2回 | `BT connected` か `BT --` | イヤホンのアドレス |
| 3回 | `up 0h05m12s` など | `heap 120KB` など |
| 4回 | 最初の表示に戻る | |

## 9. うまくいかないとき

| 症状 | 考えられる原因 | 対処 |
|---|---|---|
| 押しても何も変わらない | 挿しているピンが違う | 20番（左の列の一番下）と18番（下から3番目）か数え直す |
| 押しても何も変わらない | 常につながっている組の足を使っている | 6章のテスターで確認。対角の足に付け直す |
| 押しても何も変わらない | はんだが付いていない | 線を軽く引っ張ってみる。取れたら付け直す |
| 押していないのに勝手に切り替わる | 線やはんだ部分がほかの金属に触れている | 熱収縮チューブやテープで覆い直す |
| 1回押すと2ページ以上進む | スイッチの接触が悪い（チャタリング） | 別のスイッチに交換してみる |

**スイッチを使わずに Pico 側だけ確かめる方法**

スイッチを外し、20番ピンと18番ピンを**ジャンパワイヤ1本でつないで、すぐ離して**みてください。
これはスイッチを1回押したのと同じ意味になります。

- LCD のページが変わる → Pico とプログラムは正常です。スイッチ側（はんだ付けや足の選び方）を見直してください。
- LCD のページが変わらない → つないでいるピンの場所が違います。

---

## 10. 安全のために

- はんだごての先は **300℃以上**になります。使っていないときは必ずこて台に置いてください。
- はんだ付け中に出る煙は吸い込まないように、**換気**しながら作業してください。
- 作業が終わったら、はんだに触れた手を洗ってください。
- **Pico に USB を挿したまま**配線を変えないでください。ショートすると Pico を壊すことがあります。
