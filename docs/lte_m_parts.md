## 2. 各部品の説明

### 1. BG96 LTE ブレークアウトモジュールキット — 通信モジュール本体

- Quectel BG96 を載せた秋月製のボード。**LTE Cat-M1（LTE-M）と NB-IoT** に対応していて、Cat-M1 の最大速度は 375kbps。テキスト用途には十分。
- **LTE アンテナはチップアンテナを実装済み**なので、別に買う必要はない。GNSS アンテナ（U.FL）は使わないので不要。
- **nano SIM スロット**付き。
- レベル変換 IC（SN74LVCH16T245）が載っていて、**IO 電圧は VIO ピンに与えた電圧（1.8〜5V）**に合う。Pico の 3.3V とそのままつなげる。
- **電源は VIN に 5V（0.4A 以上を推奨）**。LiPo 1 セルの電圧を直接入れる設計にはなっていないので、昇圧が必要（→ #2）。
- **micro USB 端子が付いている**ので、PC につなげば Quectel の QNavigator などで AT コマンドを直接試せる。USB-シリアル変換は不要。
- UART は 3 系統ある。**AT コマンド用は U1（115200bps 8N1）**。U3 は GNSS 用、U2 は通常使わない。
- 注意
  - **通販は「入荷未定」**（確認時点で八潮店に 3 個）。早めに確保するか、店頭での取り寄せを相談する。
  - **出荷時は J1 のジャンパ抵抗で VIO=VIN（5V）になっている**。Pico（3.3V）とつなぐ前に、**必ず J1 を外して VIO に 3.3V を入れる**。外さずにつなぐと、Pico の GPIO に 5V がかかって壊れる。
  - 商品ページには技適の記載がない。BG96 モジュール自体は国内で使われている実績があるが、念のため同梱資料や秋月の Q&A で確認する。
- 資料: [ピン配置ガイド](https://akizukidenshi.com/goodsaffix/AE-LTECATM1-BG96-BO_card_rev0.pdf) / [回路図](https://akizukidenshi.com/goodsaffix/AE-LTE-CATM1-BG96-BO_20210902_01_sch.pdf) / [BG96 技術資料一式](https://akizukidenshi.com/goodsaffix/BG96_manual.zip)

### 2. LTC3111 昇降圧電源モジュールキット — 電池から BG96 用の 5V を作る

- 入力 2.5〜15V、出力可変（2.5〜15V）、最大 1.5A の昇降圧 DCDC。**出力を 5V に設定して** BG96 の VIN に入れる。設定方法はキットのマニュアルを参照。
- 昇降圧なので、電池が満充電（約 4.2V）から終止（約 3.0V）まで下がっても、5V を保てる。
- 最大 1.5A は入力電圧が高いときの値。単3×3本（約 3.6V）から 5V に昇圧するときは、取れる電流がこれより下がる。それでも BG96 の推奨 0.4A には余裕がある。
- はんだ付けが必要なキット。

### 3・4. 単3ニッケル水素充電池 ×3 ＋ 電池ボックス — 電源

- 3 本直列で **約 3.0〜4.2V（公称 3.6V）**。この範囲は Pico の VSYS（1.8〜5.5V）と LTC3111 の入力（2.5V〜）の両方に収まる。
- 秋月では 1 セルの LiPo 電池が見つからなかったため、扱いやすいニッケル水素にしている。秋月では入手しにくいが、小型化したくなったら LiPo ＋ 充電モジュールに替えられる。
- スイッチ付きの電池ボックスなら、そのまま電源スイッチとして使える。
- **ニッケル水素用の充電器は秋月では扱っていない**ので、家電量販店などで買う（→ 3 章）。

### 5. ショットキーダイオード 1N5819 — Pico への逆流防止

- 電池の＋ → 1N5819 → Pico の **VSYS（39 番ピン）** の向きに入れる。
- USB をつないだときに、VBUS の 5V が電池側へ逆流するのを防ぐ。Pico のデータシートにある「外部電源と USB を併用する」ときの推奨構成。

### 6. OS-CON 1000μF — 送信時の電圧降下対策

- LTE の送信時は瞬間的に大きな電流が流れる。**BG96 ボードの VIN–GND のすぐ近く**に付けて、電圧が落ちてリセットされるのを防ぐ。
- 極性があるので向きに注意する（足の長いほう、またはマークのないほうが＋）。耐圧 6.3V なので、5V ラインにだけ使う。

### 7. ピンヘッダー

- BG96 ボードはスルーホールなので、ピンヘッダーをはんだ付けしてからジャンパワイヤでつなぐ。

## 4. 配線のイメージ

LCD（GP0/GP1）とスイッチ（GP10〜13、GP15）には触れず、**UART1（GP4/GP5）**を使う。

| Pico WH | BG96 ボード | 説明 |
|---|---|---|
| GP4（物理 6 番、UART1 TX） | U1.RXD | Pico → BG96（AT コマンド） |
| GP5（物理 7 番、UART1 RX） | U1.TXD | BG96 → Pico |
| GP6（物理 9 番） | PWRKEY | 起動用。ピン配置ガイドでは「約 1 秒押して離す」。何レベルで ON になるかは回路図で確認 |
| 3V3(OUT)（物理 36 番） | VIO | **J1 を外してから**つなぐ。IO を 3.3V にする |
| GND | GND | 必ず共通にする |

電源のつなぎ方は次のとおり。

```
電池＋(3.0〜4.2V) ─┬─ 1N5819 ─→ Pico VSYS (39番)
                   └─ LTC3111 IN ── LTC3111 OUT(5V) ─┬─→ BG96 VIN
                                                     └─ OS-CON 1000μF ─ GND
電池− ──────────── 全体の GND（Pico / LTC3111 / BG96）
```

- **BG96 の電源を Pico の 3V3 や VBUS から取らないこと**。3V3 の出力は約 300mA が上限で、足りない。
- 開発中に Pico を USB でつないでいても、1N5819 があるので電池側には逆流しない。

## 5. 動作確認の順番（おすすめ）

1. BG96 ボードに SIM を挿し、**micro USB で PC につないで** QNavigator やシリアルターミナルから AT コマンドを打つ。`AT+CPIN?` → `AT+CEREG?` → `AT+QIACT` の順に、SIM 認識・網への登録・データ接続ができることを確認する。
2. J1 を外し、電池と LTC3111 から VIN に 5V を入れて単体で動かす。
3. Pico と UART でつなぎ、Pico から AT コマンドを送ってみる。
4. MQTT（BG96 内蔵の `AT+QMT*` コマンド）で、中継サーバとやりとりする。
