# 外で音楽を聞くための部品（microSD 再生・秋月電子通商で揃える版）

espoke を外に持ち出して、**音楽は microSD から BT イヤホンで再生**し、**Discord は Wi-Fi があるとき（自宅など）だけ使う**構成にするための部品リスト。
外では通信しないので、SIM や LTE モジュールはいらない。

```
外: [espoke] ── microSD の MP3 ──→ BT イヤホン（ネットは使わない）
家: [espoke] ── Wi-Fi ── MQTT ── 中継Bot ── Discord
                  └─ PC から新しい曲を SD に同期
```

価格・在庫は 2026-10-02 に秋月の通販サイトで確認した値。変わることがあるので、注文前に各ページで確認すること。

## 2. 各部品の説明

### 1. メモリーカード変換基板 CK-40（サンハヤト）

- microSD スロット（ヒロセ電機 DM3AT-SF-PEJM5、押すと出てくるプッシュ・プッシュ式）が**はんだ付け済み**の変換基板。信号線が 2.54mm ピッチの穴に出ている。
- 外形 22.86×24.13mm、厚さ 1.6mm。ピンヘッダは付いていないので、**1×8 のピンヘッダをはんだ付けする。**
- **基板には部品が何も載っていない**（プルアップ抵抗もパスコンもない）。そのため #2〜#4 を自分で付ける。
- ピン配置（基板の印刷より。差し込み口を上にして部品面から見ると、左から 1〜8）:

  | 番号 | 印刷 | SPI モードでの役割 |
  |---|---|---|
  | 1 | DAT2 | 使わない（プルアップしておく） |
  | 2 | DAT3 /CS | **CS** |
  | 3 | CMD /DI | **MOSI**（Pico → カード） |
  | 4 | VDD | 3.3V |
  | 5 | CLK | **SCK** |
  | 6 | VSS | GND |
  | 7 | DAT0 /DO | **MISO**（カード → Pico） |
  | 8 | DAT1 | 使わない（プルアップしておく） |

- 1〜8 のほかに、両脇に **FG**（スロットの金属ケース）とカード検出スイッチ（スイッチの記号が印刷された 2 つの穴、ここでは **CD** と呼ぶ）の穴がある。どちらも使わなくてよい。ユニバーサル基板の配置図（`board_layout.svg`）では、この穴の下を配線が通るので**ピンを付けない**。
- microSD は 3.3V で動くので、Pico WH と**レベル変換なしで直結できる**（LCD のような 5V 対策はいらない）。

### 2. 10kΩ 抵抗 — プルアップ用（5 本使う）

- SD カードの規格では、信号線をプルアップしておくことが求められている。付けないと、起動直後にカードの認識が不安定になることがある。
- **CS（DAT3）、MOSI（CMD）、MISO（DAT0）、DAT1、DAT2 の 5 本**を、それぞれ 10kΩ で 3.3V につなぐ。
- 特に **DAT1 と DAT2 は SPI モードでは使わないが、何もつながない状態（浮かせたまま）にしない**。

### 3・4. 0.1μF ＋ 10μF — パスコン

- カードは書き込み時などに瞬間的に電流を多く流すので、**スロットの VDD–VSS のすぐ近く**に 0.1μF と 10μF を並列に付ける。
- これがないと、BT 送信と重なったときに電圧が落ちて、読み込みエラーになることがある。

### 5. microSDHC 16GB

- 容量の目安（espoke は MP3 をそのまま再生する）:

  | 形式 | 1 時間あたり | 16GB に入る量 |
  |---|---|---|
  | MP3 192kbps | 約 86MB | 約 180 時間 |
  | MP3 320kbps | 約 144MB | 約 110 時間 |

- **FAT32 でフォーマット**して使う。SDHC（32GB 以下）なら、買ったときから FAT32 になっている。64GB 以上の SDXC は exFAT なので、FAT32 にフォーマットし直す必要がある。

### 6〜8. 電池まわり

- 単3×3本で **約 3.0〜4.2V（ニッケル水素）**。Pico の VSYS（1.8〜5.5V）に入れる。
- **1N5819 は「電池＋ → 1N5819 → VSYS（物理 39 番）」の向き**に入れる。USB をつないだときに、VBUS の 5V が電池側へ逆流するのを防ぐ。Pico のデータシートにある推奨構成。
- 電池ボックスのスイッチを、そのまま電源スイッチとして使える。
- **モバイルバッテリーを使う場合の注意**: 外では Wi-Fi が止まって消費電流が減るので、消費電流が小さいと自動で電源が切れる機種だと途中で落ちることがある。手持ちの機種で確認すること。

## 3. 配線

今の配線（I2C の GP0/GP1、スイッチの GP10〜13・GP15）とは衝突しないように、**SPI0（GP16・GP18・GP19）**を使う。
CS はどの GPIO でもよいので、ユニバーサル基板で線が交差しないように **GP20** にした（配置は `board_layout.svg`）。

| CK-40 | Pico WH | 説明 |
|---|---|---|
| ② DAT3 /CS | GP20（物理 26 番） | CS。10kΩ で 3.3V にプルアップ |
| ③ CMD | GP19（物理 25 番、SPI0 TX） | MOSI。10kΩ で 3.3V にプルアップ |
| ④ VDD | 3V3(OUT)（物理 36 番） | 0.1μF ＋ 10μF を GND との間に |
| ⑤ CLK | GP18（物理 24 番、SPI0 SCK） | プルアップしない |
| ⑥ VSS | GND（物理 23 番） | 配置図では、Pico の下の行25 を通して x=33 からつなぐ |
| ⑦ DAT0 | GP16（物理 21 番、SPI0 RX） | MISO。10kΩ で 3.3V にプルアップ |
| ① DAT2・⑧ DAT1 | （つながない） | それぞれ 10kΩ で 3.3V にプルアップ |
| カード検出スイッチ（CD） | （任意）片方を GND、もう片方を GP22（物理 29 番） | `INPUT_PULLUP` で読む。挿入時に閉じるか開くかは、テスターで確認してから使う。配置図では使っていない |

```
            3V3 ─┬────┬────┬────┬────┬──────────┬───────┐
                10k  10k  10k  10k  10k          │       │
                 │    │    │    │    │          0.1μF   10μF
 GP20 ───────────┴─── ② CS │    │    │           │       │
 GP19 ────────────────── ③ CMD   │    │          GND     GND
 GP16 ───────────────────────── ⑦ DAT0
                                     ├─ ① DAT2
                                     └─ ⑧ DAT1（DAT2 と DAT1 にも、それぞれ 10k）
 GP18 ── ⑤ CLK
 3V3  ── ④ VDD        GND ── ⑥ VSS
```

## 4. ファームの変更点（メモ）

| 箇所 | 状態 | 内容 |
|---|---|---|
| SD の初期化 | 済 | arduino-pico の `SD` ライブラリで、`SPI.setRX(16); SPI.setSCK(18); SPI.setTX(19);` を呼んでから `SD.begin(20)`（CS は GP20） |
| MP3 の再生 | 済 | PC で WAV に変換せず、**MP3 のまま** Pico 上でデコードする（`BackgroundAudio` ライブラリに入っている libmad）。44.1kHz ステレオ 192kbps で CPU の約 4 割 |
| 選曲 | 済 | `sd` で SD から連続再生。`next`・`prev`・`rand` は、最後に選んだ方（SD か Wi-Fi）に効く |
| Discord | まだ | Wi-Fi があるときだけ MQTT につなぐ。外で打ったメッセージは送信待ちとして保存し、つながったら送る。外にいた間の受信は、MQTT の永続セッション（QoS 1）で取りこぼさない |
| 曲の同期 | まだ | 自宅の Wi-Fi につながったら、PC から新しい MP3 をダウンロードして SD に保存する |

使い方や制約は README の 7.6 節。

## 5. 動作確認の順番（おすすめ）

1. CK-40 にピンヘッダー（1×8）を付け、プルアップ抵抗・パスコンと一緒に、上の表（ユニバーサル基板なら `board_layout.svg`）のとおり配線する。
2. PC で microSD を FAT32 にフォーマットし、MP3 を何曲か入れる（フォルダに分けてよい）。m4a は再生できないので、`ffmpeg -i in.m4a -c:a libmp3lame -b:a 192k out.mp3` で MP3 にしておく。
3. `sd_test` を書き込み、配線・カード・ファイル一覧・読み書きを確かめる。MP3 は espoke で再生できる形式か（44.1kHz など）も表示される。
4. espoke を書き込み、シリアルで `sd` と打って BT イヤホンで鳴らす。
5. 電池（または モバイルバッテリー）だけで動かし、外に持ち出して確認する。
