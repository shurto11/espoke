# 外で音楽を聞くための部品（microSD 再生・秋月電子通商で揃える版）

espoke を外に持ち出して、**音楽は microSD から BT イヤホンで再生**し、**Discord は Wi-Fi があるとき（自宅など）だけ使う**構成にするための部品リスト。
外では通信しないので、SIM や LTE モジュールはいらない。

```
外: [espoke] ── microSD の WAV ──→ BT イヤホン（ネットは使わない）
家: [espoke] ── Wi-Fi ── MQTT ── 中継Bot ── Discord
                  └─ PC から新しい曲を SD に同期
```

価格・在庫は 2026-10-02 に秋月の通販サイトで確認した値。変わることがあるので、注文前に各ページで確認すること。

## 2. 各部品の説明

### 1. マイクロSDカードスロット DIP化キット

- ヒロセ電機の microSD スロット（DM3AT）を 2.54mm ピッチに変換する基板と、1×14 の細ピンヘッダーのセット。**ピンヘッダーのはんだ付けが必要。**
- **基板には部品が何も載っていない**（プルアップ抵抗もパスコンもない）。そのため #2〜#4 を自分で付ける。
- ピン配置（マニュアルより）:

  | 番号 | 名前 | SPI モードでの役割 |
  |---|---|---|
  | 1 | DAT2 | 使わない（プルアップしておく） |
  | 2 | CD/DAT3 | **CS** |
  | 3 | CMD | **MOSI**（Pico → カード） |
  | 4 | VDD | 3.3V |
  | 5 | CLK | **SCK** |
  | 6 | VSS | GND |
  | 7 | DAT0 | **MISO**（カード → Pico） |
  | 8 | DAT1 | 使わない（プルアップしておく） |
  | 9 | カード検出スイッチ B | カードの有無を検出する（任意） |
  | 10 | カード検出スイッチ A | 同上 |

- microSD は 3.3V で動くので、Pico WH と**レベル変換なしで直結できる**（LCD のような 5V 対策はいらない）。
- 資料: [マニュアル](https://akizukidenshi.com/goodsaffix/K-5488_AE-MICRO-SD-DIP.pdf) / [基板寸法図](https://akizukidenshi.com/goodsaffix/AE-MICRO-SD-DIP_plot.pdf) / [スロット寸法図](https://akizukidenshi.com/goodsaffix/DM3AT-SF-PEJM5.pdf)

### 2. 10kΩ 抵抗 — プルアップ用（5 本使う）

- SD カードの規格では、信号線をプルアップしておくことが求められている。付けないと、起動直後にカードの認識が不安定になることがある。
- **CS（DAT3）、MOSI（CMD）、MISO（DAT0）、DAT1、DAT2 の 5 本**を、それぞれ 10kΩ で 3.3V につなぐ。
- 特に **DAT1 と DAT2 は SPI モードでは使わないが、何もつながない状態（浮かせたまま）にしない**。

### 3・4. 0.1μF ＋ 10μF — パスコン

- カードは書き込み時などに瞬間的に電流を多く流すので、**スロットの VDD–VSS のすぐ近く**に 0.1μF と 10μF を並列に付ける。
- これがないと、BT 送信と重なったときに電圧が落ちて、読み込みエラーになることがある。

### 5. microSDHC 16GB

- 容量の目安（`serve_music.py` と同じ 16bit PCM の WAV の場合）:

  | 形式 | 1 時間あたり | 16GB に入る量 |
  |---|---|---|
  | 44.1kHz モノラル（`serve_music.py` の既定） | 約 320MB | 約 50 時間 |
  | 44.1kHz ステレオ | 約 640MB | 約 25 時間 |

- **FAT32 でフォーマット**して使う。SDHC（32GB 以下）なら、買ったときから FAT32 になっている。64GB 以上の SDXC は exFAT なので、FAT32 にフォーマットし直す必要がある。

### 6〜8. 電池まわり

- 単3×3本で **約 3.0〜4.2V（ニッケル水素）**。Pico の VSYS（1.8〜5.5V）に入れる。
- **1N5819 は「電池＋ → 1N5819 → VSYS（物理 39 番）」の向き**に入れる。USB をつないだときに、VBUS の 5V が電池側へ逆流するのを防ぐ。Pico のデータシートにある推奨構成。
- 電池ボックスのスイッチを、そのまま電源スイッチとして使える。
- **モバイルバッテリーを使う場合の注意**: 外では Wi-Fi が止まって消費電流が減るので、消費電流が小さいと自動で電源が切れる機種だと途中で落ちることがある。手持ちの機種で確認すること。

## 3. 配線

今の配線（I2C の GP0/GP1、スイッチの GP10〜13・GP15）とは衝突しないように、**SPI0（GP16〜19）**を使う。

| SD スロット | Pico WH | 説明 |
|---|---|---|
| ② CD/DAT3 | GP17（物理 22 番） | CS。10kΩ で 3.3V にプルアップ |
| ③ CMD | GP19（物理 25 番、SPI0 TX） | MOSI。10kΩ で 3.3V にプルアップ |
| ④ VDD | 3V3(OUT)（物理 36 番） | 0.1μF ＋ 10μF を GND との間に |
| ⑤ CLK | GP18（物理 24 番、SPI0 SCK） | プルアップしない |
| ⑥ VSS | GND（物理 23 番など） | |
| ⑦ DAT0 | GP16（物理 21 番、SPI0 RX） | MISO。10kΩ で 3.3V にプルアップ |
| ① DAT2・⑧ DAT1 | （つながない） | それぞれ 10kΩ で 3.3V にプルアップ |
| ⑨・⑩ カード検出スイッチ | （任意）片方を GND、もう片方を GP22（物理 29 番） | `INPUT_PULLUP` で読む。挿入時に閉じるか開くかは、テスターで確認してから使う |

```
            3V3 ─┬────┬────┬────┬────┬──────────┬───────┐
                10k  10k  10k  10k  10k          │       │
                 │    │    │    │    │          0.1μF   10μF
 GP17 ───────────┴─── ② CS │    │    │           │       │
 GP19 ────────────────── ③ CMD   │    │          GND     GND
 GP16 ───────────────────────── ⑦ DAT0
                                     ├─ ① DAT2
                                     └─ ⑧ DAT1（DAT2 と DAT1 にも、それぞれ 10k）
 GP18 ── ⑤ CLK
 3V3  ── ④ VDD        GND ── ⑥ VSS
```

## 4. ファームの変更点（メモ）

| 箇所 | 変更内容 |
|---|---|
| WAV の解析・再生 | `parseWav(WiFiClient*)` などを、`Stream*` を受け取る形にする。SD の `File` も `Stream` なので、HTTP と SD の両方で同じコードが使える |
| 選曲 | `next`・`prev`・`rand` の対象を、SD のファイル一覧にする |
| SD の初期化 | arduino-pico の `SD` ライブラリで、`SPI.setRX(16); SPI.setCS(17); SPI.setSCK(18); SPI.setTX(19);` を呼んでから `SD.begin(17)` |
| Discord | Wi-Fi があるときだけ MQTT につなぐ。外で打ったメッセージは送信待ちとして保存し、つながったら送る。外にいた間の受信は、MQTT の永続セッション（QoS 1）で取りこぼさない |
| 曲の同期 | 自宅の Wi-Fi につながったら、`serve_music.py` から変換済みの WAV をダウンロードして SD に保存する |

## 5. 動作確認の順番（おすすめ）

1. ピンヘッダー、プルアップ抵抗、パスコンを付け、上の表のとおり配線する。
2. PC で microSD を FAT32 にフォーマットし、ffmpeg で変換した WAV を何曲か入れる（`ffmpeg -i in.mp3 -ac 1 -ar 44100 -c:a pcm_s16le out.wav`。`serve_music.py` と同じ形式になる）。
3. arduino-pico の SD ライブラリのサンプル（`listfiles` など）で、ファイル一覧が読めることを確認する。
4. espoke に SD 再生を組み込み、BT イヤホンで鳴らす。
5. 電池（または モバイルバッテリー）だけで動かし、外に持ち出して確認する。
